# Guardian Plan

1. Restate the approved outcome and exclusions.
2. Break work into bounded tasks with exact target files or components.
3. Give each task prerequisites, expected output, verification, and rollback.
4. Mark independent tasks as parallelizable without sharing unnecessary context.
5. Add specification review, quality review, and final verification gates.
6. Record the plan in the project brain before execution.

Prefer the smallest plan that safely proves the requested outcome.
